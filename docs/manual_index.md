# Core input language

These commands define the simulation domain, grid, surfaces, particles,
control flow, time integration, and output. They are part of the supported
OpenEdge input language and are documented here so an OpenEdge case can be
built without consulting another manual.

Physics-specific `fix`, `compute`, `surf_collide`, and `surf_react` styles are
listed in the main navigation by model family.
