# timestep command

## Syntax

```
timestep dt
```

dt = timestep size (time units) :ul

## Examples

```
timestep 2.0
timestep 0.003
```

## Description

Set the timestep size for subsequent simulations.

[Restrictions:] none

## Related commands

run

## Default

```
timestep 1.0
```
