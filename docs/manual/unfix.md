# unfix command

## Syntax

```
unfix fix-ID
```

fix-ID = ID of a previously defined fix :ul

## Examples

```
unfix 2
unfix lower-boundary
```

## Description

Delete a fix that was previously defined with a fix command.

[Restrictions:] none

## Related commands

fix

[Default:] none
