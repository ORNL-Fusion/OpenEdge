fix force/thermal command

Syntax: 

fix ID force/thermal Nevery bsource keyword values ...
  • ID is documented in fix command
  • force/thermal = style name of this fix command
  • Nevery = apply the force every Nevery timesteps
  • bsource = background fix-ID or bfield BxSRC BySRC BzSRC 
      background fix-ID = ID of a fix background
    supplying B and the Te, Ti gradients at the particle
  bfield BxSRC BySRC BzSRC = per-grid or per-particle sources for the
    field components (T) in OpenEdge coordinate order; each is
    c_ID[col] or p_name
  • one or more keyword/value pairs must be appended
  • keyword = ion_mass_amu, ion_thermal, or elec_thermal 
      ion_mass_amu value = background-ion mass in amu; overrides the
    single-ion mass stored by fix background
  ion_thermal values = [yes/no] [gradTiR_SRC gradTiZ_SRC]
    yes/no = enable or disable the ion thermal force (default yes
      when the keyword is present)
    gradTiR_SRC, gradTiZ_SRC = (R,Z) components of grad(Ti) (eV/m),
      required with bfield when enabled; not allowed with background
  elec_thermal values = [yes/no] [gradTeR_SRC gradTeZ_SRC]
    same as above for the electron thermal force and grad(Te)

Examples: 

fix pd background file plasma.h5 static yes
fix fth force/thermal 1 background pd ion_thermal elec_thermal
fix fth force/thermal 20 background pd ion_thermal yes elec_thermal no
fix fth force/thermal 1 bfield c_cpl[1] c_cpl[2] c_cpl[3] &
    elec_thermal c_cpl[12] c_cpl[13]

Description:

Apply the Braginskii thermal forces to charged (impurity) particles. The force acts along the local magnetic field and is proportional to the parallel gradient of the background ion and electron temperatures: 

F_par = beta_i(mu,Z) e grad_par(Ti) + alpha_e Z^2 e grad_par(Te)

The ion coefficient matches DIVIMP CIOPTN=1/3: 

beta_i = -3 [1-mu-5 sqrt(2) Z^2 (1.1 mu^(5/2)-0.35 mu^(3/2))]
             / [2.6-2 mu+5.4 mu^2]
mu = m_Z / (m_Z + m_i)

Here m_Z and Z are the impurity mass and charge state and m_i is the background-ion mass. With a single-ion plasma file, m_i is read from ion_species/mass_amu; ion_mass_amu overrides it. Multi-ion backgrounds and backgrounds without species metadata use deuterium (2.01410177811 amu) unless overridden.

The electron coefficient remains alpha_e = 0.71 (Braginskii Z_eff=1). grad_par is the component of the gradient along the unit vector of B. Both terms point toward higher temperature, i.e. typically toward the core. The ion_thermal and elec_thermal keywords select which of the two terms are applied; at least one must be enabled.

The force is applied as two half-kicks, one before and one after the particle move, so that the Boris integration remains symmetric. Each half-kick uses dt/2 * Nevery so that the impulse accumulated over Nevery steps equals the force integrated over that interval. For particles advanced in guiding-center mode the impulse is added directly to the stored parallel velocity.

With a background source, B is sampled at the particle position from the referenced fix and the temperature gradients are taken from the per-cell mesh gradient datasets of the plasma file when present, otherwise by bilinear interpolation of the regular-grid gradient fields. For 3d native backgrounds the full 3d gradient is sampled. With the bfield form, B and the (R,Z) gradient components are read from the listed sources: c_ID[col] is column col of a per-grid compute evaluated at the particle's cell (the compute is invoked by this fix), p_name is a per-particle custom floating-point vector. Gradient sources are always the cylindrical (R,Z) components; the toroidal component is taken as zero.

Using Nevery > 1 reduces the cost of the per-particle field and gradient lookups, but the impulse per application grows with Nevery. Where gradients are strong (near the separatrix or X-point) keep Nevery small or increase the pusher subcycling with the subcycles option of the global pusher command.

Neutral species are not affected.

Restrictions:

This command is part of the OPENEDGE package.

Requires either a fix background or per-grid computes providing B and the temperature gradients. Only charged species are accelerated.

Related commands:

fix cross_field_diffusion, fix coulomb/background, fix background, global

Default:

A channel keyword given without yes/no is enabled. Neither channel is active unless its keyword appears. ion_mass_amu defaults to the single-ion background metadata, or 2.01410177811 amu when the background has multiple ion species or no species metadata.
