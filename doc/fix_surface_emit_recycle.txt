fix surface/emit/recycle command :h3

[Syntax:]

fix ID surface/emit/recycle mix-ID group-ID fix-ID keyword value ... :pre

ID is documented in "fix"_fix.html command :ulb,l
surface/emit/recycle = style name of this fix command :l
mix-ID = ID of mixture to use when creating particles :l
group-ID = ID of surface group that emits particles :l
fix-ID = ID of the "fix background"_fix_background.html supplying the plasma :l
zero or more keyword/value pairs may be appended :l
keyword = {mass} or {R} or {twall} or {twall_species} or {nevery} or {region} :l
  {mass} value = main-ion mass in amu used for the sound speed
  {R} value = total recycling coefficient (0 to 1)
  {twall} value = emission temperature in Kelvin
  {twall_species} values = sp1 T1 \[sp2 T2 ...\]
    sp = species ID in the mixture
    T = emission temperature in Kelvin for that species
  {nevery} value = Nevery = emit every this many timesteps
  {region} value = region-ID = only emit from surface elements in region :pre
:ule

[Examples:]

fix rec surface/emit/recycle dgas wall pd
fix rec surface/emit/recycle dgas wall pd R 0.98 twall 500.0 &
    twall_species D 23210.0 D2 500.0 :pre

[Description:]

Emit neutral particles from the surface elements of a group at the
rate of the local plasma wall flux, i.e. model the thermal
re-emission of recycled plasma ions as neutrals.  The plasma state
(ne, Te, Ti, B) adjacent to each element is taken from the "fix
background"_fix_background.html.  Per element the Bohm wall flux is

Gamma = n c_s sin(alpha_B),   c_s = sqrt((Te+Ti)/m_i) :pre

with m_i the {mass} value and sin(alpha_B) the projection of B onto
the surface normal, and the emission rate is

dN/dt = 0.5 R Gamma A :pre

where R is the recycling coefficient (1-R is pumped) and A the element
area (the axisymmetric ring area in 2d axisymmetric mode).  The factor
1/2 balances the recombination of two atoms into one molecule at the
wall; the mixture fractions control the atom/molecule split of the
emitted species.  When the background carries a wall-face area for
each element (from the plasma-code boundary cells), that area is used
in place of the geometric element area, so the emitted total matches
the plasma-code flux budget independent of how the grid splits the
element.

Emitted particles are launched along the surface normal with a
half-Maxwellian flux distribution at the emission temperature, and
their rotational and vibrational energies are sampled at the same
temperature.  {twall} sets the temperature for every species;
{twall_species} overrides it for individual species, e.g. Franck-Condon
atoms at ~23000 K (2 eV) and wall-thermalized molecules at the wall
temperature.  Every species named in {twall_species} must exist in
the mixture.  The pairs are consumed until the next keyword or the end
of the command.

The fast (BCA) reflection channel is not part of this fix; use
"surf_react surface/pwi"_surf_react_surface_pwi.html for it on the
same surface group.  The particles created by this fix pass through
the surface collision and reaction models assigned to the element, so
they are tallied like other emitted particles.

At initialization the fix prints, once, the number of emission tasks
and the global Bohm-flux rate it will use.  Emission tasks are
rebuilt when the grid changes or the background plasma is reloaded.

[Restart, output info:]

No information about this fix is written to "binary restart
files"_restart.html.

This fix computes a global vector of length 2 which can be accessed
by various output commands.  The first element is the number of
particles emitted on the most recent emission step, the second the
cumulative number of particles emitted since the start of the run.

[Restrictions:]

This command is part of the OPENEDGE package.  It requires a "fix
background"_fix_background.html and explicit (non-implicit) surface
elements.  The {perspecies} keyword of "fix emit/surf"_fix_emit_surf.html
is accepted but has no effect; species are always drawn from the
mixture fractions.

[Related commands:]

"fix surface/emit/source"_fix_surface_emit_source.html,

[Default:]

The option defaults are mass = 2.0, R = 0.99, twall = 400.0, nevery =
1, no twall_species and no region.
