fix particulate/thermal command

Syntax: 

fix ID particulate/thermal Nevery mix-ID background bg-ID keyword value ...
  • ID is documented in fix command
  • particulate/thermal = style name of this fix command
  • Nevery = apply the thermal update every Nevery timesteps
  • mix-ID = ID of mixture containing the particulate species
  • background = required literal keyword
  • bg-ID = ID of the fix background supplying the plasma
  • zero or more keyword/value pairs may be appended
  • keyword = model or material or heating or charge or heatflux/scale or ion_mass_amu or ion_charge_state or twall_K or alpha_e or rocket_eta or emit_into or termination or dis_mass_tol 
      model value = dustt2005 or dis2021 = thermal and termination
    closure
  material value = NAME = material properties
  heating value = flux or oml or auto
    flux = Q = 0.25 sqrt(q_par^2 + q_perp^2) from the background
    oml = local electron and ion collection heating
    auto = oml when the Debye length is defined; error if R_d exceeds it
  charge value = fix-ID = ID of the matching fix particulate/charge
  heatflux/scale value = S = multiplier on the heat input (>= 0)
  ion_mass_amu value = M = background-ion mass (amu)
  ion_charge_state value = Z = background-ion charge state (> 0)
  twall_K value = T = wall temperature for radiative exchange (K)
  alpha_e value = A = evaporation (accommodation) coefficient (0,1]
  rocket_eta value = ETA = evaporation-recoil efficiency [0,1]
  emit_into value = mix-ID = create vapor particles in this mixture
  termination value = dis or dustt = override the model's rule
  dis_mass_tol value = F = relative mass at which model dis2021
    removes the particulate (0,1)

Examples: 

fix heat particulate/thermal 1 particulates background pd &
         model dustt2005 material Li heating auto alpha_e 1.0 &
         twall_K 300 emit_into lithium_vapor
fix heat particulate/thermal 1 particulates background pd &
         model dis2021 material Li heating oml charge qd

Description:

Evolve the temperature, phase, evaporation (or sublimation), mass and radius of finite-size particulates. Optionally launch the evaporated atoms as kinetic particles and apply an asymmetric evaporation-recoil force.

The surface energy balance contains the plasma heating, gray-body radiative exchange with the wall at twall_K, and the latent heat carried by the evaporated flux. Density, heat capacities, emissivity, melting point, latent heats, atomic mass and Antoine coefficients come from the material named by material. Evaporation uses the Antoine vapor pressure and a Hertz-Knudsen flux with accommodation coefficient alpha_e. An apparent-heat-capacity band handles melting. Adaptive internal substeps limit each update to 25 K and 2% radius change.

The heating keyword selects the heat input. flux (the default) uses the parallel and perpendicular heat-flux components carried by the background. oml uses local electron and ion collection; it takes the particulate charge from fix particulate/charge when present and otherwise a hydrogenic floating-potential estimate. auto uses OML collection where the Debye length is defined and stops with an error if R_d/lambda_D > 1, since a finite-size collection closure is not available. heatflux/scale multiplies the selected heat input. With model dustt2005 a negative net heat flux is clamped to zero; with model dis2021 the signed net flux enters the energy equation.

The model keyword selects the closure and its termination rule: dustt2005 (the default) removes the particulate at R/R0 = 0.1, at which point 99.9% of the initial atoms of a sphere have evaporated; the remaining 0.1% is reported as a terminal remainder. dis2021 integrates continuous evaporation down to the relative mass dis_mass_tol, accounts the remainder as evaporated and closes at 100%. termination overrides the model's rule for verification runs and is not normally needed. The charge keyword names the matching charge fix; it is required by model dis2021 with heating oml or auto.

With emit_into, each particulate spawns vapor atoms in its current grid cell: the number per update is Poisson-distributed with mean 4 pi R^2 Gamma_evap dt / fnum, the velocity is an isotropic Maxwellian at the particulate temperature, and the species is drawn from the target mixture's fractions. If fix particulate/emit assigned an nweight, the vapor source and atom tallies are scaled by it.

rocket_eta scales the recoil force from asymmetric evaporation; 0 disables it.

Restart, output info:

No information about this fix is written to binary restart files.

This fix computes a global scalar and a global vector of length 2. The scalar is the cumulative number of physical atoms evaporated, summed over all processors. Vector element 1 is the same tally; element 2 is the terminal remainder of model dustt2005 in atom equivalents. These can be accessed by any command that uses global values from a fix, e.g. stats_style.

The fix also writes the custom per-particle attributes droplet_heating_q (net heat flux, W/m^2), droplet_a_over_lambdaD (R_d/lambda_D) and droplet_oml_weight (1 when OML heating was used); model dis2021 additionally writes the individual heat channels particulate_dis_q_ion, particulate_dis_q_electron, particulate_dis_q_neutralization, particulate_dis_q_sheath, particulate_dis_q_thermionic and particulate_dis_q_secondary.

Restrictions:

This fix is part of the OPENEDGE package. It requires a fix background; heating flux and auto require that background to carry q_par/q_perp heat-flux data. The material must define rho, cp, mass_amu, hvap_J_mol and a negative antoine_b. Model dis2021 requires a material command with a provenance string and explicit rho, cp, cp_solid, mass_amu, hvap_J_mol, antoine_a, antoine_b, emissivity, tmelt_K and hmelt_J_mol; every species of the mixture must have a positive radius and a mass consistent with 4/3 pi rho R^3; with heating oml or auto it requires charge naming a fix particulate/charge using model dis2021, the same background, material and ion parameters, defined before this fix.

Related commands:

fix particulate/charge, fix particulate/drag, fix particulate/emit, material, fix background

Default:

The option defaults are model = dustt2005, material = Li, heating = flux, heatflux/scale = 1.0, ion_mass_amu = 2.0, ion_charge_state = 1, twall_K = 300, alpha_e = 1.0, rocket_eta = 0, dis_mass_tol = 1e-12, termination follows the model, no emit_into.
