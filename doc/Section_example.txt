5. Example problems :h3

The OpenEdge distribution includes an examples directory with two
kinds of cases.  Each case has its own directory with an input script
named in.*, its input data in an input sub-directory, and its checks
or plotting scripts in a scripts sub-directory.  Outputs are written
to an output sub-directory.  The README file in each directory
describes the case, how to run it and what it checks.

Verification cases ask whether OpenEdge solves the implemented model
correctly, against an analytical solution, a numerical reference or
another code.  Each has a deterministic PASS or FAIL gate and runs in
seconds to minutes on a laptop.  They are the cases to run after
changing the source.

collisions/coulomb = Coulomb slowing-down and binary thermalization against the NRL formulary
efield_polarization = polarization drift of a proton in a time-dependent electric field
ionization_recombination = oxygen charge-state balance under ADAS rates
particulates/dustt2005/uniform_plasma_benchmark = DUSTT-2005 grain model against analytic reference results
particulates/dustt2005/cat_solps_droplet_transport = DUSTT-2005 droplet transport in CAT geometry
pushers/orbit = Boris and guiding-center banana orbits in the Khan analytical field
pushers/hybrid = Boris/GCA hand-off near an absorbing wall
surface_emission/constant_flux = constant-flux emission independent of emission cadence
surface_pwi/deposit_tagging = deposit tagging and layer seeding in the PWI ledger :ul

Workflow cases are device-scale applications that demonstrate a
complete modeling chain, from a converted plasma background to
impurity or particulate transport and wall response.  They take
minutes to hours and are meant as templates.

impurity_transport/west_tungsten_transport = axisymmetric tungsten sputtering and transport in WEST
impurity_transport/rfpie_tungsten_transport = helium-driven tungsten sputtering on a biased target in RFPIE
particulates/cat_liquid_metal_divertor = lithium release from a liquid-metal divertor in CAT
particulates/st40_lithium_powder_dropper = lithium powder injection in ST40
particulates/west_boron_powder_dropper = boron powder injection in WEST :ul

Here is how you might run a verification case:

cd examples/verification/pushers/orbit
./run.sh /path/to/spa_mpi :pre

and a workflow case:

cd examples/workflows/impurity_transport/west_tungsten_transport
mpirun -np 4 /path/to/spa_mpi -in in.openedge :pre

The regression directory at the top of the distribution holds a
script that runs every registered case as a smoke test:

./regression/run_regression.sh --exe /path/to/spa_mpi :pre
