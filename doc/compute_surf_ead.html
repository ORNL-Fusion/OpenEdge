compute surf/ead command

Syntax:

compute ID surf/ead group-ID mix-ID Emax NbE Amax NbA [quantities q1 q2 ...]
  • group-ID = surface group to tally on
  • mix-ID = mixture used to filter incident species
  • Emax = maximum incident energy in eV
  • NbE = number of energy bins
  • Amax = maximum incidence angle in degrees (from surface normal)
  • NbA = number of angle bins
  • quantities = one or more of sum_weight, sum_particles, hist

Examples:

compute cEAD surf/ead exposedTarget_0 TantalumSource 300 150 90 90
compute cEAD surf/ead exposedTarget_0 TantalumSource 300 150 90 90 quantities hist

compute cEAD surf/ead exposedTarget_0 TantalumSource 300 150 90 90 &
        quantities sum_weight sum_particles hist
fix     fEAD ave/surf exposedTarget_0 1 100 100 c_cEAD[*] ave one
dump    dEAD surf exposedTarget_0 100 output/ead.surf.0 id f_fEAD[*]

Description:

This OpenEdge compute tallies a per-surface energy-angle distribution (EAD) for incident particles on explicit surface elements. Only surfaces in group-ID and incident species in mix-ID are included.

Angles are measured from the outward surface normal and binned from 0 to Amax degrees. Energies are binned from 0 to Emax eV. For units si, kinetic energy is computed in Joules and converted internally to eV before binning.

Output info:

This compute produces a per-surf array. Column layout depends on the selected quantities:

  • sum_weight: one column (weighted incident strike count)
  • sum_particles: one column (unweighted incident strike count)
  • hist: NbA*NbE columns, flattened with ibin = ia*NbE + ie

If quantities are omitted, default order is: sum_weight, sum_particles, hist.

Related commands: compute surf, fix ave/surf, dump surf
