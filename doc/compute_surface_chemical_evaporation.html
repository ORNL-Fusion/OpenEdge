compute surface/chemical/evaporation command

Syntax: 

compute ID surface/chemical/evaporation group-ID tsurf name sticking value
  • ID is documented in compute command
  • surface/chemical/evaporation = style name of this compute command
  • group-ID = ID of surface group to evaluate
  • tsurf = required keyword
  • name = name of the per-surf custom attribute holding the surface temperature (degrees C)
  • sticking = required keyword
  • value = alpha_s = sticking (evaporation) coefficient (> 0)

Examples: 

compute cevap surface/chemical/evaporation divertor tsurf Tsurf_lm sticking 1.0
fix femit surface/emit/source LiSource divertor cevap perspecies no &
    normal yes nlaunch_total 200 model thermal_tsurf Tsurf_lm

Description:

Compute the lithium evaporation flux of each surface element in the group from its surface temperature. The temperature is read from the per-surf custom attribute name (in degrees C), typically Tsurf_lm written by fix surface/state/lm.

The vapor pressure follows the Antoine relation 

p_vap(T) = 10^(A - B/T) * 101325 Pa

with A = 5.66797 and B = 8310.41 K for lithium (valid for 298 K <= T <= 1600 K), and the flux is the Hertz-Knudsen expression 

Gamma_evap(T) = alpha_s * p_vap(T) / sqrt(2 pi m_Li k_B T)

where alpha_s is the sticking value. The flux is zero below 298.15 K and for surfaces outside the group.

The per-surf values are meant to be fed to fix surface/emit/source as the emission source for Li atoms, or written with dump surf.

Output info:

This compute calculates a per-surf vector, with one value per surface element owned by the processor. The value is the evaporation flux in atoms/m^2/s; it is zero for surfaces not in the group.

The vector can be accessed by any command that uses per-surf values from a compute as input, e.g. dump surf, fix ave/surf or fix surface/emit/source.

Restrictions:

This compute is part of the OPENEDGE package. The custom attribute named by tsurf must exist when the compute is initialized (it is created by fix surface/state/lm). The command requires at least 6 arguments (counting the compute ID and style), so tsurf name alone is rejected: the sticking keyword and its value must be given even for the default value of 1.0.

Related commands:

fix surface/state/lm, compute surface/chemical/adatom, fix surface/emit/source

Default:

sticking = 1.0 internally, but see the restriction above.
