fix efield/particle command

Syntax: 

fix ID efield/particle Ex Ey Ez
  • ID is documented in fix command
  • efield/particle = style name of this fix command
  • Ex,Ey,Ez = name of a particle-style variable for each component of the electric field (V/m), or NULL

Examples: 

variable Ex particle 1.0e3
fix fe efield/particle Ex NULL NULL
fix fb bfield/particle NULL NULL Bz0
global efield particle fe 1
global bfield particle fb 1

Description:

Define an electric field that is evaluated per particle from particle-style variables. The three arguments name the variables (without the "v_" prefix) that give the x, y, and z components of E in V/m in the simulation coordinate slots. A component given as NULL is left unset and treated as zero.

The fix does not act on its own. It is made the electric field of the charged-particle pusher with the efield particle setting of the global command, which also specifies how often (Nfreq timesteps) the variables are re-evaluated. Every time the field is evaluated, each named variable is computed for all particles owned by the processor and the results are stored in a per-particle array with one column per non-NULL component.

This fix is the companion of fix bfield/particle and is used by verification cases with analytic fields, e.g. the E x B polarization-drift test. Production simulations take their electric field from a fix background through the plasma value of the global pusher keyword instead.

Restart, output info:

No information about this fix is written to binary restart files.

This fix computes a per-particle array with one column for each non-NULL component, in x, y, z order, holding the last evaluated field values. It is intended to be consumed by the global efield setting; the columns can also be accessed by the dump particle command as f_ID[N].

Restrictions:

This command is part of the OPENEDGE package. It is only enabled if OpenEdge was built with that package. See the Section 2.3 section for more info.

Exactly three arguments must be given. Each non-NULL argument must name an existing particle-style variable when the run begins.

Related commands:

fix bfield/particle, global, variable

Default: none
