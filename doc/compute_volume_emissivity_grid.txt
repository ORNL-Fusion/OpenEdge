compute volume/emissivity/grid command :h3

[Syntax:]

compute ID volume/emissivity/grid group-ID mix-ID keyword values ... :pre

ID is documented in "compute"_compute.html command :ulb,l
volume/emissivity/grid = style name of this compute command :l
group-ID = group ID for which grid cells to perform calculation on :l
mix-ID = mixture ID whose species groups are tallied :l
the {pec} and {plasma_compute} keywords are required :l
keyword = {pec} or {plasma_compute} or {pec_units} :l
  {pec} values = elem pec_id line = selector of the photon emissivity
    coefficient table {/volume/pec/elem/pec_id/line} in the process
    database
  {plasma_compute} value = ID of a "compute plasma/fields"_compute_plasma_fields.html
    providing Te and ne
  {pec_units} value = {cm3s} or {m3s} = units of the stored PEC table :pre
:ule

[Examples:]

compute cpl plasma/fields all file plasma.h5
compute cem volume/emissivity/grid all allW pec w 4009 wi_4295_pec &
    plasma_compute cpl
fix aem ave/grid all 1 1000 1000 c_cem\[*\]
dump 1 grid all 1000 emis.*.dat id f_aem\[*\] :pre

[Description:]

Compute the volumetric line emissivity of a spectral line in every
grid cell,

emissivity = ne * nz * PEC(Te,ne)   (photons/m^3/s/sr) :pre

where nz is the number density of the emitting species group, ne and
Te the local electron density and temperature, and PEC the photon
emissivity coefficient of the line. One column is produced per species
group of the mixture {mix-ID}, so a mixture whose groups are the
individual charge states yields one synthetic-emission map per charge
state.

The PEC table is read from the OpenEdge process database
({database/processes.h5}) under {/volume/pec/elem/pec_id/line}, which
holds log10(PEC) on a log10(Te) x log10(ne) grid ingested from
open-ADAS adf15 files. The table is bilinearly interpolated in
log-log space and clamped to its bounds. {pec_units cm3s} (the ADAS
convention) converts the coefficient to m^3/s; use {m3s} if the table
is already in SI.

The species density in each cell is accumulated from the per-particle
weight {pweight} of "fix particle/weight"_fix_particle_weight.html,
so flux-weighted emission is represented correctly: nz = sum(pweight)
* cellweight / volume. Te and ne are queried from the referenced
plasma/fields compute at the cell center. Cells with no particles of
the group, or where Te or ne is not positive, get zero emissivity.

The compute performs its tally when invoked and applies the plasma
factors in a post-processing step, so it can be time averaged with
"fix ave/grid"_fix_ave_grid.html, in which case the accumulated
weights are divided by the number of samples before the emissivity is
formed.

[Output info:]

This compute calculates a per-grid array with one column per species
group of the mixture. The values can be used by any command that uses
per-grid values from a compute as input, such as "dump
grid"_dump.html or "fix ave/grid"_fix_ave_grid.html.

[Restrictions:]

This command is part of the OPENEDGE package.

Requires "fix particle/weight"_fix_particle_weight.html (the {pweight}
attribute) and a "compute plasma/fields"_compute_plasma_fields.html.
The process database must contain the requested PEC table, otherwise
the compute stops with an error.

[Related commands:]

"compute plasma/fields"_compute_plasma_fields.html, "fix
particle/weight"_fix_particle_weight.html, "fix
volume/chem/adas"_fix_volume_chem_adas.html, "fix
ave/grid"_fix_ave_grid.html

[Default:]

The option default is pec_units = cm3s.
