fix efield/particle command :h3

[Syntax:]

fix ID efield/particle Ex Ey Ez :pre

ID is documented in "fix"_fix.html command :ulb,l
efield/particle = style name of this fix command :l
Ex,Ey,Ez = name of a "particle-style variable"_variable.html for each
  component of the electric field (V/m), or NULL :l
:ule

[Examples:]

variable Ex particle 1.0e3
fix fe efield/particle Ex NULL NULL
fix fb bfield/particle NULL NULL Bz0
global efield particle fe 1
global bfield particle fb 1 :pre

[Description:]

Define an electric field that is evaluated per particle from
particle-style variables.  The three arguments name the variables
(without the "v_" prefix) that give the x, y, and z components of E
in V/m in the simulation coordinate slots.  A component given as NULL
is left unset and treated as zero.

The fix does not act on its own.  It is made the electric field of
the charged-particle pusher with the {efield particle} setting of the
"global"_global.html command, which also specifies how often (Nfreq
timesteps) the variables are re-evaluated.  Every time the field is
evaluated, each named variable is computed for all particles owned by
the processor and the results are stored in a per-particle array
with one column per non-NULL component.

This fix is the companion of "fix
bfield/particle"_fix_bfield_particle.html and is used by verification
cases with analytic fields, e.g. the E x B polarization-drift test.
Production simulations take their electric field from a "fix
background"_fix_background.html through the {plasma} value of the
"global pusher"_global.html keyword instead.

:line

[Restart, output info:]

No information about this fix is written to "binary restart
files"_restart.html.

This fix computes a per-particle array with one column for each
non-NULL component, in x, y, z order, holding the last evaluated
field values.  It is intended to be consumed by the "global
efield"_global.html setting; the columns can also be accessed by
the "dump particle"_dump.html command as f_ID\[N\].

:line

[Restrictions:]

This command is part of the OPENEDGE package.  It is only enabled if
OpenEdge was built with that package.  See the "Section
2.3"_Section_start.html#start_3 section for more info.

Exactly three arguments must be given.  Each non-NULL argument must
name an existing particle-style variable when the run begins.

[Related commands:]

"fix bfield/particle"_fix_bfield_particle.html,
"global"_global.html, "variable"_variable.html

[Default:] none
