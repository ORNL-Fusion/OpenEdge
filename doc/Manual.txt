Version info: :h4

The OpenEdge version is the git tag of the release, such as 26.04,
printed to the screen and log file at the start of every run and shown
at the top of this page.  Development builds append the number of
commits since the tag and the commit hash, as reported by "git
describe".

If you browse the HTML pages in the doc directory of your checkout,
they describe the version you have. :ulb,l

The "PDF file"_Manual.pdf in the doc directory is regenerated at each
release. :ule,l

OpenEdge is a kinetic transport code for the plasma edge and for
plasma-material interaction.  It follows neutral atoms and molecules,
impurity ions, and dust or droplet particulates through prescribed
plasma and magnetic-field backgrounds taken from edge fluid codes such
as SOLPS-ITER, SOLEDGE3X, OEDGE and EMC3-EIRENE.  Particles are pushed
with Boris or guiding-center integrators, undergo ADAS atomic
processes, Coulomb collisions and cross-field transport, and interact
with the wall through sputtering, reflection, recycling and evolving
surface composition.

OpenEdge is built on "SPARTA"_sparta, the Direct Simulation Monte Carlo
code developed at Sandia National Laboratories.  SPARTA provides the
hierarchical Cartesian grid, cut-cell surfaces, particle storage, MPI
parallelism and the Kokkos performance-portability layer.  The input
language documented here is SPARTA's, extended with OpenEdge commands
and styles.  OpenEdge is developed at Oak Ridge National Laboratory and
is distributed under the GNU General Public License version 2, the
same license as SPARTA.

:link(sparta,https://sparta.github.io)
