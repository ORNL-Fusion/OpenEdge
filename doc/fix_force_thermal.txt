:line

fix force/thermal command :h3

[Syntax:]

fix ID force/thermal Nevery bsource keyword values ... :pre

ID is documented in "fix"_fix.html command :ulb,l
force/thermal = style name of this fix command :l
Nevery = apply the force every Nevery timesteps :l
bsource = {background} fix-ID or {bfield} BxSRC BySRC BzSRC :l
  {background} fix-ID = ID of a "fix background"_fix_background.html
    supplying B and the Te, Ti gradients at the particle
  {bfield} BxSRC BySRC BzSRC = per-grid or per-particle sources for the
    field components (T) in OpenEdge coordinate order; each is
    {c_ID\[col\]} or {p_name} :pre
one or more keyword/value pairs must be appended :l
keyword = {ion_thermal} or {elec_thermal} :l
  {ion_thermal} values = \[yes/no\] \[gradTiR_SRC gradTiZ_SRC\]
    yes/no = enable or disable the ion thermal force (default yes
      when the keyword is present)
    gradTiR_SRC, gradTiZ_SRC = (R,Z) components of grad(Ti) (eV/m),
      required with {bfield} when enabled; not allowed with {background}
  {elec_thermal} values = \[yes/no\] \[gradTeR_SRC gradTeZ_SRC\]
    same as above for the electron thermal force and grad(Te) :pre
:ule

[Examples:]

fix pd background file plasma.h5 static yes
fix fth force/thermal 1 background pd ion_thermal elec_thermal
fix fth force/thermal 20 background pd ion_thermal yes elec_thermal no
fix fth force/thermal 1 bfield c_cpl\[1\] c_cpl\[2\] c_cpl\[3\] &
    elec_thermal c_cpl\[12\] c_cpl\[13\] :pre

[Description:]

Apply the Braginskii thermal forces to charged (impurity) particles.
The force acts along the local magnetic field and is proportional to
the parallel gradient of the background ion and electron
temperatures:

F_par = beta_i Z^2 e grad_par(Ti) + alpha_e Z^2 e grad_par(Te) :pre

with beta_i = 2.6 (ion thermal force, heavy-impurity limit) and
alpha_e = 0.71 (electron thermal force, Z_eff = 1). Both coefficients
are fixed. Z is the particle charge state and grad_par is the
component of the gradient along the unit vector of B. Both terms point
toward higher temperature, i.e. typically toward the core. The
{ion_thermal} and {elec_thermal} keywords select which of the two
terms are applied; at least one must be enabled.

The force is applied as two half-kicks, one before and one after the
particle move, so that the Boris integration remains symmetric. Each
half-kick uses dt/2 * Nevery so that the impulse accumulated over
Nevery steps equals the force integrated over that interval. For
particles advanced in guiding-center mode the impulse is added
directly to the stored parallel velocity.

With a {background} source, B is sampled at the particle position from
the referenced fix and the temperature gradients are taken from the
per-cell mesh gradient datasets of the plasma file when present,
otherwise by bilinear interpolation of the regular-grid gradient
fields. For 3d native backgrounds the full 3d gradient is sampled.
With the {bfield} form, B and the (R,Z) gradient components are read
from the listed sources: {c_ID\[col\]} is column col of a per-grid
compute evaluated at the particle's cell (the compute is invoked by
this fix), {p_name} is a per-particle custom floating-point vector.
Gradient sources are always the cylindrical (R,Z) components; the
toroidal component is taken as zero.

Using Nevery > 1 reduces the cost of the per-particle field and
gradient lookups, but the impulse per application grows with Nevery.
Where gradients are strong (near the separatrix or X-point) keep
Nevery small or increase the pusher subcycling with the {subcycles}
option of the "global pusher"_global.html command.

Neutral species are not affected.

[Restrictions:]

This command is part of the OPENEDGE package.

Requires either a "fix background"_fix_background.html or per-grid
computes providing B and the temperature gradients. Only charged
species are accelerated.
