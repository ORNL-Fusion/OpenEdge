:line

fix coulomb/binary command :h3

[Syntax:]

fix ID coulomb/binary Nevery source :pre

ID is documented in "fix"_fix.html command :ulb,l
coulomb/binary = style name of this fix command :l
Nevery = apply the collision operator every Nevery timesteps :l
source = {background} fix-ID or {plasma} TeSRC NeSRC :l
  {background} fix-ID = ID of a "fix background"_fix_background.html
    supplying Te and ne at the particle position
  {plasma} TeSRC NeSRC = sources for the electron temperature (eV)
    and density (m^-3); each is {c_ID\[col\]} (column col of a
    per-grid compute) or {p_name} (per-particle custom vector) :pre
:ule

[Examples:]

fix pd background file plasma.h5 static yes
fix fcp coulomb/binary 1 background pd :pre

fix fcp coulomb/binary 2 plasma c_cpl\[7\] c_cpl\[10\] :pre

[Description:]

Apply binary Coulomb collisions between the charged simulation
particles themselves, cell by cell, using the Nanbu (1997) scattering
operator with Takizuka-Abe style random pairing. Use this fix when the
kinetic species are dense enough that self-collisions matter; scatter
against the fluid background plasma is handled separately by "fix
coulomb/background"_fix_coulomb_background.html.

On each step where the fix acts, the charged particles in every grid
cell are shuffled and paired sequentially. If the count is odd, the
last particle is paired with a randomly chosen earlier partner. For
each pair the relative velocity g is rotated by an angle chi sampled
from the Nanbu distribution with scattering parameter

s = (qA qB)^2 n lnLambda dt / (4 pi eps0^2 mu^2 g^3) :pre

where mu is the reduced mass, dt = Nevery * timestep, and n is the
density of collision partners in the cell, computed from the charged
simulation particles as N_charged * fnum / V_cell. Both particles of a
pair are updated so that momentum and kinetic energy are conserved
exactly.

The plasma {source} is used only for the Coulomb logarithm, lnLambda =
max(2, ln(12 pi ne lambda_D^3)), evaluated from Te and ne averaged
over the two partners of a pair. Per-grid compute sources are read at
the particles' cell; the referenced computes are invoked by this fix
when needed.

Neutral species are ignored. Cells with fewer than two charged
particles are skipped. The operator is applied at the end of the
step, after the particle move.

[Restrictions:]

This command is part of the OPENEDGE package.

Requires either a "fix background"_fix_background.html or a per-grid
compute providing Te and ne. The partner density uses the global
{fnum} weight of the "global"_global.html command, not per-particle
weights.

[Related commands:]

"fix coulomb/background"_fix_coulomb_background.html, "fix
background"_fix_background.html

[Default:] none
