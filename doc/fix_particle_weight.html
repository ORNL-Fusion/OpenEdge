fix particle/weight command

Syntax: 

fix ID particle/weight
  • ID is documented in fix command
  • particle/weight = style name of this fix command

Examples: 

fix pw particle/weight
fix femit surface/emit/source LiSource divertor cevap perspecies no &
    nlaunch_total 200 model thermal
compute cgw grid/weighted all LiAll nrho_w u_w temp_w

Description:

Create the per-particle weight attribute used by the weighted emission and diagnostic commands of OpenEdge. The fix adds a custom per-particle floating-point attribute named pweight (see the custom command) that records how many physical particles each simulation particle represents. The weighted emitters such as fix surface/emit/source write this attribute when they insert a particle, and compute grid/weighted reads it to form properly normalized densities, fluxes, and moments.

A weight is required whenever emission rates vary across the wall or between sources, since the launched particles then represent different numbers of physical particles. Without this fix the weighted emitters have nowhere to store the weight and refuse to run in their weighted modes.

Particles that are not created by a weighted emitter, e.g. those inserted by create_particles, fix emit/face, or surface reactions, receive the default weight fnum (see the global command), both at the start of a run for existing particles whose weight is still zero and at insertion time for new particles. This makes the weighted diagnostics consistent with their unweighted counterparts for unweighted particles. A weight already set to a non-zero value by an emitter is never overwritten.

Like any custom attribute, pweight follows the particle through sorting, cloning, splitting, and migration between processors. Only one fix of this style should be defined in a simulation.

Restart, output info:

The pweight attribute is a custom per-particle attribute and is written to binary restart files with the particles. If it is already present when the fix is defined, e.g. after read_restart, the existing attribute is reused.

This fix produces no output of its own. The weights can be written by the dump particle command as p_pweight.

Restrictions:

This command is part of the OPENEDGE package. It is only enabled if OpenEdge was built with that package. See the Section 2.3 section for more info.

The command takes no arguments.

Related commands:

compute grid/weighted, fix surface/emit/source, custom

Default: none
