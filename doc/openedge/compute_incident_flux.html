compute incident/plasma/flux command

Syntax:

compute ID incident/plasma/flux surfgroup-ID file plasma.h5 values ...

ID is documented in compute command
incident/plasma/flux = preferred style name of this compute command
surfgroup-ID = surface group ID
values = one or more output fields

Output values:

  • nflux_incident = total incident ion flux (all ion species)
  • nflux_normal = incident normal ion flux (all ion species)
  • nflux_species N = incident flux for ion species slot N (1-based)

Examples:

compute cgam incident/plasma/flux 1 file input/plasma.h5 nflux_incident nflux_normal
compute cgam incident/plasma/flux 1 file input/plasma.h5 nflux_species 1

Description:

This compute samples plasma ion data from plasma.h5 on the 2D r,z mesh and interpolates incident flux to each surface element in the requested surface group.

For each surface, the compute uses the local surface normal and evaluates plasma values at a small offset from the wall. It probes both normal directions and keeps the side with larger incident flux for robust wall sampling.

Normal flux uses inward projection on the wall normal: Gamma_n = n * max(0, -v dot n_hat).

Velocity source for normal projection is selected in this order:
1) per-species components ions/parr_flow_r, ions/parr_flow_t, ions/parr_flow_z
2) single-ion components parr_flow_r, parr_flow_t, parr_flow_z
3) fallback reconstruction from parallel flow and magnetic field: v = v_par * Bhat, using br,bt,bz

Thus, if only parr_flow is available, normal flux still works when br,bt,bz are present in the same plasma.h5.

Expected plasma.h5 datasets:

Required: r, z, dens_i, parr_flow
Optional multi-ion: ions/dens, ions/parr_flow, ions/parr_flow_r/t/z
Optional B-field fallback: br, bt, bz
Optional metadata: ion_species/spec_index

Notes:

Species index in nflux_species N is the stored species slot (1-based), not atomic number.

Related commands:

compute plasma/fields, dump surf, fix emit/surf

Default:

No defaults for required file and output values.
