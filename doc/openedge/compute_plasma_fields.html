compute plasma/fields command

Syntax:

compute ID plasma/fields group-ID mode args values ...
  • ID is documented in compute command
  • plasma/fields = style name of this compute command
  • group-ID = grid group ID
  • mode = file or constant

Mode forms:

compute ID plasma/fields group-ID file plasma.h5 bfield.h5 values ...
compute ID plasma/fields group-ID constant keyword values ...

Constant keywords:

magnetic_field Br Bt Bz
electric_field Er Et Ez
temp_e value
temp_i value
dens_e value
dens_i value
parrflow value

Output values:

Cylindrical components:

br bt bz
er et ez
vr vt vz

Cartesian aliases:

bx by (bz shared)
ex ey (ez shared)
vx vy (vz shared)

Scalars:

temp_e temp_i dens_e dens_i parrflow
epar
grad_te_r grad_te_t grad_te_z
grad_ti_r grad_ti_t grad_ti_z

Examples:

compute cplasma plasma/fields all file plasma.h5 bfield.h5 br bt bz temp_e dens_e
compute cconst plasma/fields all constant magnetic_field 0 0 2.5 electric_field 0 0 0 temp_e 10 temp_i 10 dens_e 1e19 dens_i 1e19 parrflow 0 br bt bz er et ez

Description:

This compute samples plasma and magnetic data from 2D r,z tables (HDF5 file mode) or from constant values (constant mode), and outputs per-grid fields.

OpenEdge/SPARTA may run in 2D (r,z) or 3D Cartesian (x,y,z). Plasma data remains cylindrical. Native outputs are cylindrical (br/bt/bz, er/et/ez, vr/vt/vz).

In 3D Cartesian runs, aliases bx/by, ex/ey, and vx/vy are computed by rotating cylindrical vectors at each grid-cell center using the local toroidal angle around the domain centerline in x,y.

epar is the parallel electric field from the electron pressure term: epar = -(bhat dot grad(pe)) / (ne*e), with pe = e*ne*Te when Te is in eV and ne in 1/m^3. This also assumes grad_te_* inputs are in eV/m. Here bhat is the unit vector along B.

Notes on scope:

Current epar output includes only the electron-pressure-gradient contribution (the -(bhat dot grad pe)/(ne*e) term). It does not yet include additional generalized Ohm's law terms (e.g. resistive/current term, electron-inertia/time-derivative term, or potential-solve based electric field). For WEST workflows, externally supplied electric field maps (e.g. efield.h5 with er/et/ez) may therefore have larger amplitude and smoother structure than this pressure-only epar.

Removed outputs:

Surface/sheath outputs are not provided by this compute. mindist, surfid, and nesheath are removed.

Restrictions:

Input plasma and magnetic tables are 2D cylindrical maps on r,z. Requested value names must be from the lists above.

Related commands:

compute, dump, fix viscous

Default: none
