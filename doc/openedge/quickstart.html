OpenEdge Quickstart (Droplet + Evap + Viscous)

What is OpenEdge?

OpenEdge is a Plasma Material Interaction (PMI) package in SPARTA. All core SPARTA functionality is inherited (input language, solver flow, grid/particle infrastructure, and standard commands). OpenEdge adds PMI-focused models and commands while preserving SPARTA behavior unless explicitly extended.

Goal: run droplet particles with evaporation state update and viscous drag/gravity, then dump droplet properties.

Key commands:

  • fix evaporation
  • fix viscous
  • dump particle
  • variable

Minimal template:

seed                12345
dimension           2
boundary            r r p
global              gridcut 0.0 comm/sort no

create_box          -20 20  -20 20.8  -0.05 0.05
create_grid         100 100 1
balance_grid        rcb cell

species             droplet.species Li
mixture             Droplet Li frac 1.0 nrho 1
read_particles      source.1 0

fix fevap evaporation 1 Droplet mass 2.796e-10 radius 5.0e-5 temp 773.15 heatflux/constant 0.0

variable te grid "10"
variable ti grid "10"
variable ni grid "1.0e20"
variable vp grid "0"
variable Br grid "0"
variable Bt grid "0"
variable Bz grid "0"
fix fvis viscous 1 2.0 1 plasma te ti ni vp bfield Br Bt Bz gravity 0 0 -9.81

variable pmass particle mass
dump d1 particle all 100 dump.droplet id type x y z vx vy vz v_pmass temp radius

timestep            1.0e-5
run                 10000

Dump fields:

  • temp and radius are native particle dump attributes
  • mass is output as particle variable: variable pmass particle mass then v_pmass

Notes:

  • Evaporation style name is evaporation
  • Current evaporation implementation is 2d-only
  • After source edits, rebuild before validation:

For drag/gravity-only validation (no evaporation active), omit fix fevap ... and seed droplet state directly in fix viscous, for example:

fix fvis viscous 1 2.0 1 plasma te ti ni vp bfield Br Bt Bz gravity 0 0 -9.81 mass 2.796e-10 radius 5.0e-5 temp 773.15
cd src
make clean-mpi
make mpi -j8

For standalone gravity tests in this codebase, current syntax is:

fix g1 gravity all 0.0 0.0 -9.81

Geometry note for gravity/viscous:

  • Cartesian 3d uses (vx,vy,vz)
  • Axisymmetric (r,z,phi) uses (v_r,v_z,v_phi)
