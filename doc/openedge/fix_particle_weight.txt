fix particle/weight command :h3

[Syntax:]

fix ID particle/weight :pre

ID is documented in "fix"_../fix.html command
particle/weight = style name of this fix command :ul

[Description:]

This fix creates a per-particle custom attribute named {pweight} (type
double, per-particle vector).  It is required by
"fix emit/surf/pmi"_fix_emit_surf_pmi.html when the {nlaunch} keyword
is used, and by "compute grid/weighted"_compute_grid_weighted.html for
density diagnostics.

The {pweight} attribute stores the number of real particles each
simulation particle represents.  It is set at emission time and
preserved through transport, ionization, and collisions.

The attribute is automatically included in restart files and can be
output via particle dumps using {p_pweight}.

[Examples:]

fix pw particle/weight :pre

dump dpart particle all 1000 output/state id type x y z vx vy vz p_pweight :pre
