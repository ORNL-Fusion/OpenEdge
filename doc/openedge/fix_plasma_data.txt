fix plasma/data command :h3

[Syntax:]

fix ID plasma/data file plasma.h5 [equilibrium file.equ] [static yes] :pre
fix ID plasma/data constant keyword values ... [equilibrium file.equ] [static yes] :pre

ID = user-chosen fix identifier :ulb,l
file = read plasma data from an HDF5 background file :l
constant = use uniform inline plasma/magnetic values :l
equilibrium = optional equilibrium file used for psi queries and optional B derivation :l
static = optional yes/no flag; {yes} keeps the data fixed after first load :l,ule

[Constant-mode keywords:]

{ne} or {dens_e} value = uniform electron density (m^-3) :ulb,l
{te} or {temp_e} value = uniform electron temperature (eV) :l
{ni} or {dens_i} value = uniform ion density (m^-3), defaults to {ne} :l
{ti} or {temp_i} value = uniform ion temperature (eV), defaults to {te} :l
{parr_flow} value = uniform parallel flow magnitude (m/s) :l
{parr_flow_r} {parr_flow_t} {parr_flow_z} = uniform cylindrical flow components (m/s) :l
{grad_te_r} {grad_te_t} {grad_te_z} = uniform electron-temperature gradients :l
{grad_ti_r} {grad_ti_t} {grad_ti_z} = uniform ion-temperature gradients :l
{epar} value = uniform parallel electric field (V/m) :l
{br} {bz} {bt} = uniform cylindrical magnetic field components (T) :l
{r_bounds} rmin rmax = optional synthetic R extent override :l
{z_bounds} zmin zmax = optional synthetic Z extent override :l,ule

[Examples:]

# File-backed background used directly by particle transport:
fix pd plasma/data file input/plasma.h5 static yes :pre

# Minimal inline constant background for Boris/sheath tests:
fix pd plasma/data constant ne 1.0e19 te 10.0 ni 1.0e19 ti 10.0 br 0.0 bz 0.0 bt 1.0 :pre

# Use the same backend for particle transport and optional grid diagnostics:
fix pd plasma/data file input/plasma.h5 static yes
compute cwest plasma/fields all plasma_data pd bx by bz temp_e dens_e
global bfield_compute pd
global sheath geom_compute cgeom plasma_fix pd :pre

# Drive impurity transport fixes directly from the same shared background:
fix pd plasma/data file input/plasma.h5 static yes
fix ftf thermal_force 1 plasma_data pd ion_thermal yes elec_thermal yes
fix fnanbu coll/nanbu 100 plasma_data pd nobinary background 2.0 1.0
fix fcd cross_diffusion 10 plasma_data pd D_perp 0.1 gradient_pinch 2.0 :pre

[Description:]

{fix plasma/data} is the canonical OpenEdge background-data store for
plasma, magnetic-field, and optional equilibrium data.  It is read once
and then queried by other fixes and computes.

The intended usage is:

Particle transport queries the fix directly:
{global bfield_compute pd}
{global sheath geom_compute cgeom plasma_fix pd} :ulb,l

Impurity transport fixes can also query the same backend directly:
{fix ... thermal_force ... plasma_data pd}
{fix ... coll/nanbu ... plasma_data pd}
{fix ... cross_diffusion ... plasma_data pd} :l

Optional grid diagnostics wrap the same data through:
{compute ... plasma/fields ... plasma_data pd} :l,ule

This avoids maintaining separate file paths for plasma moments, magnetic
field, and particle-side samplers.

[File mode:]

The plasma HDF5 file is a cylindrical {R,Z} background.  Common datasets
are:

{r} {z} : 1D coordinates :ulb,l
{dens_e} {temp_e} : electron density and temperature :l
{dens_i} {temp_i} : ion density and temperature :l
{parr_flow} and/or {parr_flow_r} {parr_flow_t} {parr_flow_z} :l
{grad_te_r} {grad_te_t} {grad_te_z} :l
{grad_ti_r} {grad_ti_t} {grad_ti_z} :l
{epar} : optional parallel electric field :l
{br} {bz} {bt} : optional magnetic field components :l,ule

If an equilibrium file is provided and {br/bz/bt} are absent, the fix can
derive the magnetic field from the equilibrium.

[Constant mode:]

Constant mode creates a synthetic uniform {2 x 2} {R,Z} backing grid so the
existing interpolation API works unchanged.  In normal use you do not need
to specify {r_bounds} or {z_bounds}; they default to the simulation box.

This mode is intended for:

Boris regression tests :ulb,l
sheath smoke tests :l
ADAS/Nanbu transport debugging with controlled inputs :l,ule

[Default:]

No default source mode.  Either {file} or {constant} must be specified.
