fix evaporation command

Syntax:

fix ID evaporation nevery mix-ID keyword values ...
  • ID is documented in fix command
  • evaporation = style name of this fix command
  • nevery = perform update every this many timesteps
  • mix-ID = mixture ID to which evaporation is applied
  • keyword/value pairs: 
      mass value                = initial particle mass seed (kg)
  radius value              = initial particle radius seed (m)
  temp value                = initial particle temperature seed (K)
  heatflux/constant value   = uniform heat flux (W/m^2)
  heatflux/file filename    = HDF5 heat-flux map

Examples:

fix fevap evaporation 1 Droplet mass 2.796e-10 radius 5.0e-5 temp 773.15 heatflux/constant 5.0e6
fix fevap evaporation 1 Droplet mass 2.796e-10 radius 5.0e-5 temp 773.15 heatflux/file heatflux.h5

Model solved (current implementation):

dr_d/dt = -(A_M/rho_L) G_evap
dT_d/dt = [3/(rho_L C_p r_d)] [Q_s - G_evap (DeltaH_vap/N_A)]

Q_s is either constant or interpolated from heatflux.h5. The evaporation update is applied as symmetric half-steps: START_OF_STEP (dt/2) and END_OF_STEP (dt/2), so one full dt per active step where ntimestep % nevery == 0.

Droplets are removed after 90% mass loss (mass <= 0.1 * reference mass).

Expected HDF5 layout for heatflux/file:

  • Coordinates (choose one): 
    1) grid/Rc (nr,), grid/Zc (nz,)
2) grid/R (nz,nr), grid/Z (nz,nr)
3) R (nz,nr), Z (nz,nr)
  • Field dataset: 
    fields/q_mag (nz,nr)   or   q_mag (nz,nr)
  • Reader validation: 
    nr>=2, nz>=2
q_mag shape must match (nz,nr)
axes monotonic increasing
non-finite/negative q_mag are clamped to 0

Expected HDF5 layout for plasma fields (used elsewhere):

r (nr,), z (nz,)
required 2D fields (nz,nr):
dens_e, temp_e, dens_i, temp_i,
parr_flow, parr_flow_r, parr_flow_t, parr_flow_z,
grad_te_r, grad_te_t, grad_te_z,
grad_ti_r, grad_ti_t, grad_ti_z

Restrictions:

Current evaporation implementation is restricted to 2d geometry for heat-flux interpolation.

Related commands:

compute plasma/fields, fix viscous, dump, variable

Default: none. One heat-flux mode (heatflux/constant or heatflux/file) must be provided.
