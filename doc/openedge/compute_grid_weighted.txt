compute grid/weighted command :h3

[Syntax:]

compute ID grid/weighted group-ID mix-ID value1 value2 ... :pre

ID is documented in "compute"_../compute.html command
grid/weighted = style name of this compute command
group-ID = group ID for which grid cells to perform calculation on
mix-ID = mixture ID to define groups :ul

[Values:]

{nrho_w} = weighted number density \[m^-3\]
{massrho_w} = weighted mass density \[kg/m^3\]
{n_w} = weighted count (sum of pweight in cell)
{pxrho_w} = weighted x-momentum density
{pyrho_w} = weighted y-momentum density
{pzrho_w} = weighted z-momentum density
{kerho_w} = weighted kinetic energy density :ul

[Description:]

This compute is analogous to "compute grid"_../compute_grid.html but uses
per-particle weights ({pweight} custom attribute) instead of the global
{fnum}.  It requires "fix particle/weight"_fix_particle_weight.html.

For weighted number density:

{nrho_w = sum(pweight_i) * cellweight / volume}

compared to standard {compute grid nrho}:

{nrho = count * fnum * cellweight / volume}

The weighted form gives the correct physical density when particles
carry individual weights set by "fix emit/surf/pmi nlaunch"_fix_emit_surf_pmi.html.

Output is a per-grid array with {ngroup * nvalue} columns, where ngroup
is the number of groups in the specified mixture.  It can be used with
"fix ave/grid"_../fix_ave_grid.html for time averaging and
"dump grid"_../dump.html for output.

[Examples:]

fix pw particle/weight
compute cwden grid/weighted all species nrho_w
fix fwden ave/grid all 1 500 5000 c_cwden\[*\] ave running
dump dwden grid all 5000 output/density id xc yc f_fwden\[*\] :pre
