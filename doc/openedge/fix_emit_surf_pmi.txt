fix emit/surf/pmi command :h3

[Syntax:]

fix ID emit/surf/pmi mix-ID surfgroup-ID compute-ID keyword values ... :pre

ID, fix, and mix-ID are documented in "fix"_../fix.html command
emit/surf/pmi = style name of this fix command
surfgroup-ID = surface group that emits particles
compute-ID = per-surf compute that provides flux (typically {compute pmi/surf/data}) :ul

[Keywords:]

{flux_index N} = use column N from per-surf array output (1-based)
{n M} = constant multiplier mode; {n 0} uses direct flow mode
{normal yes/no} = apply stream speed in surface-normal direction
{nlaunch N} = per-particle weight mode: emit N particles per surface element per step
{flux_thresh F} = skip surface elements with flux below F \[m^-2 s^-1\] (default 0) :ul

[Description:]

This fix inserts particles from selected surfaces using a per-surface
flux source.

[Standard mode (default):]

For flow mode ({n 0}, default), the insertion target for each surface
task is:

{ntarget = flux * area * dt / fnum}

where {flux} is read from the referenced per-surf compute, {area} is the
surface/cell overlap area, {dt} is timestep, and {fnum} is global particle
weight.  Each emitted particle represents {fnum} real particles.

[Per-particle weight mode (nlaunch):]

When {nlaunch N} is specified, a fixed number N of particles is emitted
from each surface element at every timestep, regardless of the local
flux magnitude. Each particle carries a per-particle weight:

{pweight = flux * area * dt / N}

stored as the {pweight} custom attribute.  This mode requires
"fix particle/weight"_fix_particle_weight.html to be active.  Density
should be computed with "compute grid/weighted"_compute_grid_weighted.html
which uses sum(pweight)/volume instead of count*fnum/volume.

This decouples statistical quality from source strength: weak sources
get the same number of test particles as strong sources, avoiding the
problem where {flux * area * dt / fnum << 1} produces zero particles
from low-flux regions.

The {flux_thresh} keyword filters out surfaces with negligible sputtering
flux, preventing emission of near-zero-weight particles that waste CPU
without contributing to the physical result.

For a vector per-surf compute, flux is taken directly from that vector.
For an array per-surf compute, use {flux_index N} to select the column.

This fix is intended for plasma-material source terms such as sputtered
neutral emission from {compute pmi/surf/data sputter_flux_total}.

[Examples:]

compute cpmi pmi/surf/data 1 file input/plasma.h5 input/8_on_74.h5 \
projectile_slots 2 9 sputter_flux_total :pre

# Standard mode (fnum-based)
fix femit emit/surf/pmi tungstenSource 1 cpmi perspecies no normal yes :pre

# Per-particle weight mode
fix pw particle/weight
fix femit emit/surf/pmi tungstenSource 1 cpmi perspecies no normal yes \
nlaunch 5 flux_thresh 1e10 :pre

[Notes:]

If grid adapts during run, any grid-based fields used by movers should be
recomputed with nonzero global field frequency.
