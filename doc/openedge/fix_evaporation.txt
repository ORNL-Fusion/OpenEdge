fix evaporation command :h3

[Syntax:]

fix ID evaporation nevery mix-ID keyword values ... :pre

ID is documented in "fix"_../fix.html command
evaporation = style name of this fix command
nevery = perform update every this many timesteps
mix-ID = mixture ID to which evaporation is applied
keyword = one or more optional keywords
  {mass} value = initial particle mass seed (kg)
  {radius} value = initial particle radius seed (m)
  {temp} value = initial particle temperature seed (K)
  {heatflux/constant} value = uniform surface heat flux (W/m^2)
  {heatflux/file} filename = HDF5 heat flux map :ul

[Examples:]

fix fevap evaporation 1 Droplet mass 2.796e-10 radius 5.0e-5 temp 773.15 heatflux/constant 5.0e6
fix fevap evaporation 1 Droplet mass 2.796e-10 radius 5.0e-5 temp 773.15 heatflux/file heatflux.h5 :pre

[Model solved (current implementation):]

For each active droplet, OpenEdge updates radius and temperature using

dr_d/dt = -(A_M/rho_L) G_evap
dT_d/dt = [3/(rho_L C_p r_d)] [Q_s - G_evap (DeltaH_vap/N_A)] :pre

where {Q_s} is either constant or interpolated from {heatflux.h5}, and
{G_evap} is the code Antoine/kinetic evaporation flux fit.

The fix is integrated as two symmetric half-steps:
- START_OF_STEP: dt/2
- END_OF_STEP: dt/2 :ul

so evaporation advances one full dt whenever {ntimestep % nevery == 0}.

Droplets are removed when mass falls below 10% of reference mass
(90% mass loss criterion).

For compatibility with movers that use species mass, the implementation
also synchronizes {species[ispecies].mass} to updated droplet mass when
the new mass is positive/finite.

[Expected HDF5 layout for {heatflux/file}:]

Supported coordinate layouts (choose one):
1) legacy axes
  - {grid/Rc} shape (nr,)
  - {grid/Zc} shape (nz,)
2) 2D grid coordinates
  - {grid/R} shape (nz,nr), {grid/Z} shape (nz,nr)
3) root-level 2D coordinates
  - {R} shape (nz,nr), {Z} shape (nz,nr) :ul

Heat flux field dataset (required):
- {fields/q_mag} shape (nz,nr)
or
- {q_mag} shape (nz,nr) :ul

Validation in reader:
- nr>=2 and nz>=2
- q_mag shape must match (nz,nr)
- axes must be monotonic increasing
- non-finite/negative q_mag values are clamped to 0 :ul
- if primary interpolation yields zero, implementation also tries a
  transposed q_mag index path for robustness with ambiguous file layouts :ul

[Expected HDF5 layout for plasma fields (used elsewhere):]

The plasma field reader expects in {plasma.h5}:
- {r} (nr,), {z} (nz,)
- required 2D fields (nz,nr):
  {dens_e,temp_e,dens_i,temp_i,
   parr_flow,parr_flow_r,parr_flow_t,parr_flow_z,
   grad_te_r,grad_te_t,grad_te_z,
   grad_ti_r,grad_ti_t,grad_ti_z} :ul

[Per-cell grid output (SOLPS coupling):]

Each invocation of {fix evaporation} registers three per-grid-cell
accumulators accessible as {f_ID[1]}, {f_ID[2]}, {f_ID[3]} in SPARTA
scripts.  They are zeroed once at the start of each active timestep and
accumulate contributions from every droplet in the cell across both
half-kicks (start_of_step and end_of_step):

{Column layout (1-based in scripts):}

f_ID[1]  dm_kg     mass lost per cell per full step (kg)
f_ID[2]  dn_atoms  atoms lost per cell per full step (dimensionless)
f_ID[3]  heat_J    heat absorbed from plasma per cell per half-step (J) :pre

{Equations:}

dm_kg    = rho * (4/3) * pi * (r_old^3 - r_new^3)   [kg, >= 0]

dn_atoms = dm_kg / A_M                                [atoms]

heat_J   = Q_s * 4*pi * r_new^2 * dt_half            [J] :pre

where:
- {rho}    = 534 kg/m^3 (liquid Li density)
- {A_M}    = 1.53e-26 kg (Li atom mass)
- {r_old}  = droplet radius before the half-step (m)
- {r_new}  = droplet radius after the half-step (m)
- {Q_s}    = surface heat flux at the droplet position (W/m^2)
- {dt_half} = dt/2 (half-step duration, s) :ul

The second half-kick (end_of_step) adds to the same accumulator, so
{f_ID[1] and f_ID[2] represent the net mass/atom loss over one full
timestep dt = 2*dt_half.}

{Typical script usage for SOLPS coupling:}

# time-average dm_kg and dn_atoms over one dump interval (Ndump steps)
fix fml  ave/grid all 1 ${Ndump} ${Ndump} f_fevap[1] f_fevap[2]
dump d_ml grid all ${Ndump} mass_loss.txt id xc yc f_fml[1] f_fml[2] :pre

{Post-processing (Python) — Li source rate for SOLPS:}

# source_rate [atoms/m^3/s] = mean_atoms_per_step / (dt * cell_vol)
# where mean_atoms_per_step = f_fml[2] from mass_loss.txt
# and cell_vol is computed from the grid geometry (e.g. xc/yc spacings) :pre

[Restrictions:]

Current implementation enforces 2d geometry for evaporation/heat-flux
interpolation.

[Related commands:]

"fix"_../fix.html, "compute plasma/fields"_compute_plasma_fields.html,

[Default:]

No defaults for required arguments. One heat-flux mode
({heatflux/constant} or {heatflux/file}) must be provided.
