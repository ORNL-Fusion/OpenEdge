fix viscous command

Syntax:

fix ID viscous nevery A_bg Z_bg plasma TeSrc TiSrc NiSrc VparSrc bfield BrSrc BtSrc BzSrc [gravity gx gy gz] [mass m0] [radius r0] [temp T0] [diag yes|no] [diag/every N]
  • ID is documented in fix command
  • viscous = style name of this fix command
  • nevery = perform update every this many timesteps
  • A_bg = background ion atomic mass (amu)
  • Z_bg = background ion charge state
  • TeSrc,TiSrc,NiSrc,VparSrc = plasma sources
  • BrSrc,BtSrc,BzSrc = magnetic field sources
  • optional gravity gx gy gz = constant acceleration components
  • optional mass m0 = one-time particle mass seed (kg)
  • optional radius r0 = one-time particle radius seed (m)
  • optional temp T0 = one-time particle temperature seed (K)
  • optional diag yes|no = runtime diagnostics print toggle (default no)
  • optional diag/every N = diagnostics interval in timesteps (default 100)

Each source can be either a grid-style variable name or c_ID[I] from a per-grid compute.

For compute sources, this fix supports both mapped tally-backed per-grid computes and standard per-grid array/vector computes (e.g. compute plasma/fields).

Examples:

fix fv viscous 1 2.0 1 plasma te ti ni vpar bfield Br Bt Bz
fix fv viscous 1 2.0 1 plasma te ti ni vpar bfield Br Bt Bz gravity 0 0 -9.81
fix fv viscous 1 2.0 1 plasma te ti ni vpar bfield Br Bt Bz gravity 0 0 -9.81 mass 2.796e-10 radius 5.0e-5 temp 773.15
fix fv viscous 5 2.0 1 plasma c_pf[1] c_pf[2] c_pf[3] c_pf[4] bfield c_bf[1] c_bf[2] c_bf[3]

Description:

Apply Epstein drag to particles with optional gravity forcing. The model is:

dv/dt = -nuE * (v - u_parallel) + g

and is integrated in symmetric half-steps around advection.

If mass/radius/temp are provided, missing particle values are seeded one time (only when current value <= 0), which is useful for no-evaporation drag/gravity tests.

Geometry handling:

  • Cartesian 2d/3d: components map directly to (vx,vy,vz)
  • Axisymmetric (r,z,phi): (gx,gy,gz) is rotated into (v_r,v_z,v_phi) using particle phi

Validation note:

For viscous/gravity validation, analytic assumptions must match case inputs: initial v_z(0) and background parallel flow u_g (from VparSrc and B direction). If these assumptions are inconsistent, simulation/model curves will disagree even with a correct implementation.

Restart, output info:

This fix does not currently output a fix scalar/vector/array.

Restrictions:

Do not combine gravity ... inside this fix with a separate fix gravity in the same run.

Related commands:

fix evaporation, fix gravity, variable, compute

Default: optional gravity disabled
