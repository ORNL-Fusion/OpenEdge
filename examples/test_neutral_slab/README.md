# test_neutral_slab — 1-D neutral transport channels

Four 1-D slab setups, each isolating one neutral-transport channel in
`fix chem/adas`. A monoenergetic neutral beam is puffed from `xlo` into
a uniform plasma background; grid diagnostics dump the steady-state
density (and temperature, for CX) across the slab.

| Case | Deck | What it tests |
|---|---|---|
| iz      | `in.slab_iz`      | Ionization only (Mode A: delete on ionization). |
| recycle | `in.slab_recycle` | Ionization + cosine reflection at the `xhi` wall. |
| cx      | `in.slab_cx`      | CX thermalization + ionization at different Te, Ti. |
| diss    | `in.slab_diss`    | D₂ electron-impact dissociation only. |

## Files

| File | Purpose |
|---|---|
| `in.slab_{iz,recycle,cx,diss}` | Input decks. |
| `input/neutral.species` + `.reactions` | Atomic D + iz/rec/cx channel table. |
| `input/neutral_cx.reactions` | Channel table for the CX case. |
| `input/neutral_diss.{species,reactions}` | D₂ + dissociation channel table. |
| `input/slab.surf` + `input/wall.exchange` | Reflecting wall geometry + PWI reaction (recycle case). |
| `input/plasma_cx.h5` | Mesh-free plasma.h5 for the CX case (generated by `make_plasma_cx.py`). |
| `plot_slab.py` | Parses `output/slab_<case>.grid`, writes `<case>.png`. |
| `make_plasma_cx.py` | Generates `input/plasma_cx.h5`. |

## Run

```bash
source /opt/intel/oneapi/setvars.sh --force
BIN=/home/cloud/buildOpenEdge/src/spa_mpi

# one-time: regenerate the CX plasma file if missing
python3 make_plasma_cx.py

mpirun -np 4 $BIN -in in.slab_iz
python3 plot_slab.py iz

mpirun -np 4 $BIN -in in.slab_recycle
python3 plot_slab.py recycle

mpirun -np 4 $BIN -in in.slab_cx
python3 plot_slab.py cx

mpirun -np 4 $BIN -in in.slab_diss
python3 plot_slab.py diss
```

Each deck writes its own `output/slab_<case>.grid`. The plot script
renders `<case>.png` in this directory (log-y density decay for iz/
recycle/diss; density + T_D two-panel for cx).

## Setup

All four cases:
- 2-D slab, 0 ≤ x ≤ 0.6 m, thin y / periodic
- 3 eV monoenergetic beam from the xlo face (Franck-Condon)
- Uniform plasma background (`compute plasma/fields constant` for the
  simple cases; `fix plasma/data file plasma_cx.h5` for CX, which needs
  local Ti in the per-particle pcache)
