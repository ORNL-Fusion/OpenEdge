# Neutral-transport workflows

Cases in which OpenEdge plays the part of the kinetic neutral code of a coupled
edge simulation: one batch of every neutral source is emitted and followed to
extinction, and the volume sources the plasma code needs (particle, momentum
and energy source moments, neutral densities) are accumulated per cell and
exported on a regular R–Z grid.

| Directory | Application |
|---|---|
| `ltx_lithium_neutral_sources/` | Li sputtered by the H⁺ wall flux and H recycled through the Li wall of LTX-β, on a SOLEDGE3X plasma |
