# Particulate and liquid-material workflows

This group contains device applications involving droplets, injected powder,
or liquid-metal plasma-facing surfaces.

| Directory | Application |
|---|---|
| `cat_liquid_metal_divertor/` | CAT liquid-metal surface sources and Li droplets |
| `lithium_droplet_transport/` | Generic Li-droplet trajectory workflow |
| `st40_lithium_powder_dropper/` | ST40 Li-powder injection and ablation |
| `west_boron_powder_dropper/` | WEST B-powder injection and ablation |
